# v0: Hello LLM

**Goal:** get a working AI call with as little code as possible. v0 is naive on purpose. It shows that the AI works, and everything wrong with it becomes the roadmap for the following iterations.

## What's included

```
AI-Demo/
├── hello.py           # ~12-line script: one question in, one answer out
├── requirements.txt   # openai, python-dotenv
└── .env.example       # endpoint, API key, deployment name
```

## How it works

`hello.py` uses the standard `openai` Python SDK against Azure OpenAI's v1-compatible endpoint. It reads a question from the terminal, sends it with a one-line system prompt, and prints the reply:

```python
client = OpenAI(
    base_url=f"{os.environ['AZURE_OPENAI_ENDPOINT']}/openai/v1/",
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
)

response = client.chat.completions.create(
    model=os.environ["AZURE_OPENAI_DEPLOYMENT"],
    messages=[
        {"role": "system", "content": "You are Contoso's IT helpdesk assistant."},
        {"role": "user", "content": question},
    ],
)
```

The same client works with both Azure OpenAI and OpenAI, so there's no Azure-specific wrapper to explain.

## Demo script

1. **"How do I connect a second monitor?"** You get a good, generic answer: the AI works.
2. **"What's Contoso's VPN policy for contractors?"** It answers confidently with a policy it made up. This is a hallucination.
3. **"Reset my password."** It can only describe the steps. It can't do anything.
4. **"What did I just ask?"** It doesn't know, because every run is stateless.
5. **Open `.env`.** It holds a long-lived master key in plain text.

## What's wrong with v0, and where it gets fixed

| Problem | Fixed in |
|---|---|
| API key in a file; anyone holding it has full access | v1: managed identity |
| Runs on a laptop; resources created by hand | v1: Container Apps + `azd`/Bicep |
| Prompt hardcoded in code; free-text output | v2: versioned prompts, structured outputs |
| No conversation memory | v3: Cosmos DB session state |
| Makes up company facts | v4: grounding with Azure AI Search |
| Can't take actions | v5–v7: tools, agent loop, human-in-the-loop |
| No input/output safety | v8: Azure AI Content Safety |
| No visibility into cost or latency | v9: OpenTelemetry + Application Insights |
| No way to tell whether a change made it worse | v10: evaluations as a CI gate |
| No retries, rate limits or fallback; single region | v11: API Management AI gateway |
