# Administrator Rights (IT-POL-015)

## Default
Contoso employees do not have local administrator rights on their laptops. Most software can be installed from the Company Portal without admin rights (see IT-POL-005).

## Temporary admin rights
Developers and IT staff can get temporary admin rights through Admin By Request. Open the Admin By Request app, give a reason, and you get admin rights for 60 minutes. Every elevation is logged and reviewed by Security.

## Permanent admin rights
Permanent local admin rights are not granted. Staff who need them regularly should use a Microsoft Dev Box, which is a cloud PC with full admin rights, isolated from the Contoso network.
